# 📚 考研英语词汇刷题与背词系统

一个专为考研学子打造的轻量、高效、美观的英语词汇自测与强化系统。内置考研高频核心词汇、真题例句、考点搭配与助记解析。支持**电脑端**、**手机端网页**及**安卓离线独立 App** 全平台使用！

---

## 📱 手机端使用方式

再也不需要连接电脑或配局域网 IP，现在有两种更便捷的使用方式：

### 方式一：手机浏览器在线访问（即开即用，免安装）
直接在手机浏览器（Safari、Chrome、夸克、微信等）中打开线上网站：
👉 **[点击直接访问在线刷题网站](https://lianghongyu1127.github.io/Test/)**

> 💡 **小技巧（类似 App 体验）**：在手机浏览器菜单中点击 **「添加到主屏幕」**，桌面上就会生成一个应用图标，支持全屏沉浸式刷题，体验如同原生 App。

---

### 方式二：下载安卓离线独立 App（完全脱网可用）
如果你在自习室、图书馆网络不好，或想关闭网络专注背词，可以直接下载 APK 安装包：

1. 打开本仓库的 👉 **[GitHub Releases 发布页面](https://github.com/lianghongyu1127/Test/releases)**
2. 展开最新版本的 **Assets**，点击下载 `app-debug.apk` 到手机上安装。
3. **特性**：
   - **100% 离线可用**：全部题库和功能内置，开启飞行模式也能秒开。
   - **物理返回键保护**：答题过程中轻扫屏幕边缘或按返回键不会误退出，主界面双击才会退出。
   - **进度持久化**：背词历史、错题本自动保存，断电不丢失。

## 💻 电脑端使用方式

### 方式一：在线网页直接刷题
直接在电脑浏览器访问：`https://lianghongyu1127.github.io/Test/` 即可。

### 方式二：本地离线打开
直接使用 Edge / Chrome 浏览器双击打开项目根目录下的 `index.html` 即可畅快刷题。

> 若需要启动本地调试服务，可在终端执行：
> ```bash
> python -m http.server 8080
> ```
> 随后在浏览器打开 `http://localhost:8080`。

## ✨ 核心功能亮点

- 🎯 **多种训练模式**：
  - **词汇自测模式**：海量考研真题词汇，支持词性与词族二级标签精细筛选。
  - **每日一练**：每日专属词汇打卡挑战，养成背词好习惯。
  - **闯关模式**：阶梯式难度进阶，挑战词汇极限。
- 📖 **深度考点解析**：
  - 核心释义、真题搭配短语（Collocations）、词族派生（Word Family）。
  - 记忆法（Mnemonic）、考研真题溯源与权威例句展示。
  - 内置词汇标准发音朗读。
- 📕 **智能错题本**：
  - 做错题目自动归入错题库，支持针对错题专项复练，掌握后可一键移除。
- 📊 **学习进度看板**：
  - 实时统计已学词汇、正确率、掌握进度，数据自动保存在本地，随时恢复上次进度。

## ⌨️ 电脑端快捷键支持

| 快捷键 | 功能 |
|:---|:---|
| `A` / `B` / `C` / `D` | 快速选择对应选项 |
| `←` 左方向键 | 查看上一题 |
| `→` 右方向键 | 查看下一题 / 提交下一题 |
| `Enter` 回车键 | 确认答案 / 下一题 |
