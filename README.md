# 📘 软件工程刷题系统

一个轻量级的本地刷题小工具，包含 118 道软件工程题目（选择题、填空题、判断题），支持电脑和手机同时使用。

---

## 📁 文件说明

| 文件 | 说明 |
|------|------|
| `index.html` | 刷题主页面 |
| `questions.json` | 题库数据（118 道去重题目） |
| `parse_questions.py` | PDF 解析脚本（仅开发时使用，刷题不需要） |
| `题库1.pdf` / `题库 - 副本1.pdf` | 原始题库 PDF |

---

## 🚀 启动方式

### 前提条件

电脑上需要安装 Python 3（Windows 一般自带 `py` 启动器）。

### 第一步：打开终端

- **方法 1**：在文件夹空白处按住 `Shift` + 右键，选择「在此处打开 PowerShell 窗口」
- **方法 2**：按 `Win + R`，输入 `cmd`，然后用 `cd` 命令切换到题库目录：
  ```
  cd /d E:\Data\pdf
  ```

### 第二步：启动本地服务器

在终端中输入以下命令：

```bash
py -3 -m http.server 8080
```

看到类似以下输出说明启动成功：

```
Serving HTTP on :: port 8080 (http://[::]:8080/) ...
```

> 💡 如果 `py` 命令不可用，可以尝试 `python -m http.server 8080`

### 第三步：打开浏览器访问

在浏览器地址栏输入：

```
http://localhost:8080
```

即可开始刷题！

### 关闭服务器

在终端中按 `Ctrl + C` 即可停止服务器。

## 📱 手机端访问方法

手机和电脑必须连接**同一个 Wi-Fi 网络**。

### 第一步：查看电脑的局域网 IP

在电脑终端中输入：

```bash
ipconfig
```

找到当前使用的网络适配器（通常是「无线局域网适配器 WLAN」），记下 **IPv4 地址**，例如：

```
无线局域网适配器 WLAN:
   IPv4 地址 . . . . . . . . . . : 192.168.1.105
```

### 第二步：确保防火墙允许访问

Windows 防火墙可能会阻止手机访问，需要放行 8080 端口：

1. 第一次启动 `http.server` 时，Windows 可能会弹出防火墙提示，**点击「允许访问」**
2. 如果没有弹窗，手动设置：
   - 打开「Windows 安全中心」→「防火墙和网络保护」→「高级设置」
   - 左侧点击「入站规则」→ 右侧「新建规则」
   - 选择「端口」→ 下一步 → 输入 `8080` → 「允许连接」→ 全选网络类型 → 命名为「刷题服务器」

### 第三步：手机浏览器访问

在手机浏览器中输入（把 IP 替换成你电脑的实际 IP）：

```
http://192.168.1.105:8080
```

即可在手机上刷题！页面已做了响应式适配，手机上显示效果良好。

## ⌨️ 快捷键（电脑端）

| 快捷键 | 功能 |
|--------|------|
| `←` 左方向键 | 上一题 |
| `→` 右方向键 | 下一题 |
| `A` / `B` / `C` / `D` | 直接选择答案（选择题） |
| `Enter` | 提交答案（填空题） |

## 🔧 如果需要重新解析 PDF

如果修改了 PDF 题库内容，需要重新生成 `questions.json`：

```bash
py -3 parse_questions.py
```

> 此操作需要 `pymupdf` 库，安装命令：`py -3 -m pip install pymupdf`
